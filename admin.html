Saving commits data/cv.json to your site’s repository. A GitHub Action then rebuilds the homepage and the CV PDF from it, usually within two minutes. The Present and Future tabs keep your progress and notes in a separate private repository, so they are never published with the site. To save, this page needs a GitHub access token. It is kept only in this browser and sent only to GitHub.

  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Under Repository access, choose Only select repositories and pick kabirsinghji.github.io and your private admin-data repository. (Already have a token? Edit it and add admin-data.)
  3. Under Permissions → Repository permissions, set Contents to Read and write and Actions to Read-only.
  4. Generate it, copy it, and paste it below.
